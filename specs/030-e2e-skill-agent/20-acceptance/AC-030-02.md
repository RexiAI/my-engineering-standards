# AC-030-02 — Skill references (progressive disclosure)

## AC-030-02-01 — All six reference files exist
Given the directory `skills/e2e-testing/references/` exists
When its contents are listed
Then the following files exist:
  - `setup.md`
  - `writing-tests.md`
  - `running-debugging.md`
  - `bug-bash.md`
  - `ci.md`
  - `mobile-rn.md`

## AC-030-02-02 — Each reference file is referenced from SKILL.md
Given `skills/e2e-testing/SKILL.md` content
When each reference filename is searched within it
Then `references/setup.md` appears
And `references/writing-tests.md` appears
And `references/running-debugging.md` appears
And `references/bug-bash.md` appears
And `references/ci.md` appears
And `references/mobile-rn.md` appears

## AC-030-02-03 — No nested reference chains
Given each file in `skills/e2e-testing/references/*.md`
When its content is searched for relative links to other reference files (patterns like `](setup.md)`, `](writing-tests.md)`, etc.)
Then no reference file contains a link to another reference file in the same directory
