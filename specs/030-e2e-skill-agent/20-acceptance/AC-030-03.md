# AC-030-03 — Skill assets (config example)

## AC-030-03-01 — Config example file exists
Given the path `skills/e2e-testing/assets/e2e.config.example.ts`
When checked for existence
Then the file exists

## AC-030-03-02 — Model ids from environment variables
Given the file `skills/e2e-testing/assets/e2e.config.example.ts`
When its content is searched for model configuration
Then `process.env` is used for model id values (e.g. `E2E_AGENT_MODEL`, `E2E_JUDGE_MODEL`)
And no hardcoded model id string (e.g. `gpt-`, `claude-`, `gemini-`) is present

## AC-030-03-03 — Port-0 pattern and app launch present
Given the file content
When searched for app launch configuration
Then a `targets` array with `app.command` is present
And `url` with port `0` or `{port}` substitution pattern is present

## AC-030-03-04 — Budgets and cache modes configured
Given the file content
When searched for budget and cache configuration
Then budget configuration (model calls / actions / timeout) is present (as values or comments)
And cache mode configuration (`read-write` / `read-only` / `off`) is present

## AC-030-03-05 — Telemetry opt-out and tests path present
Given the file content
When searched for telemetry and tests configuration
Then a comment or configuration referencing `E2E_TELEMETRY_DISABLED` is present
And tests path `tests/**/*.e2e.ts` or equivalent glob is configured
And no `.env` file loading (no `dotenv`, no `loadEnv`, no `.env` import) is present
And no secrets, tokens, or credentials are present
