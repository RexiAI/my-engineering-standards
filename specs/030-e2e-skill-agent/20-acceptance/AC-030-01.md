## AC-030-01-01 — Frontmatter exists with required fields

Then the frontmatter contains a `name` field
And the frontmatter contains a `description` field

## AC-030-01-02 — Name matches directory
Given the file is at `skills/e2e-testing/SKILL.md`
When the `name` field is read from frontmatter
Then its value is exactly `e2e-testing`

## AC-030-01-03 — Name format valid
Given the `name` field value
When validated against regex `^[a-z0-9]+(-[a-z0-9]+)*$`
Then it matches
And the length is ≤64 characters

## AC-030-01-04 — Description non-empty and within limit

Then it is ≥1 character
And it is ≤1024 characters

## AC-030-01-05 — Body line count within limit
