# AC-030-06 — Conditional model wiring

> This task is **explicitly conditional**. It is executed only if the human
> reviewer decides to add `e2e-runner` to `opencode.json`'s agent block. If
> skipped, all three scenarios are considered N/A and pass by default.

## AC-030-06-01 — opencode.json e2e-runner entry uses env reference
Given `opencode.json`
When the `agent` block is examined
Then if an `e2e-runner` entry exists, its `model` value is exactly `"{env:SPEC_E2E_RUNNER_MODEL}"`
And no literal model or provider id is present in that entry

## AC-030-06-02 — config/model.local.env.example defines the var
Given `config/model.local.env.example`
When searched for `SPEC_E2E_RUNNER_MODEL`
Then if the task was executed, a line defining `SPEC_E2E_RUNNER_MODEL` with a default value exists
And the definition follows the same comment+value pattern as other `SPEC_*_MODEL` entries

## AC-030-06-03 — scripts/model-env.vars.sh roster updated
Given `scripts/model-env.vars.sh`
When examined
Then if the task was executed:
  - `SPEC_E2E_RUNNER_MODEL` is in the `MODEL_ENV_VARS` array
  - `e2e-runner` is in the `MODEL_ENV_AGENTS` array
  - `model_env_var_for_agent()` maps `e2e-runner` to `SPEC_E2E_RUNNER_MODEL`
And `scripts/check-model-env.sh` exits 0
