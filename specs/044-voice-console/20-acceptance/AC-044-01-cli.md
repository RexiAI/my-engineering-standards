# AC-044-01: CLI surface, configuration, run artifacts

## AC-044-01-01 — Help lists modes and exit codes
Given `scripts/voice/voice-console.mjs` on disk
When it runs with `--help`
Then exit code is 0
And stdout names `narrate`, `converse`, and `control`
And stdout names `0`, `2`, `3`, `4`, and `5` with their meanings

## AC-044-01-02 — Print-config shape
Given no configuration environment variables set
When `voice-console.mjs --print-config` runs
Then exit code is 0
And stdout parses as exactly one JSON object
And its keys include `mode`, `control`, `session`, `agent`, `opencodeUrl`, `audioIn`, `audioOut`, `asr`, `tts`, `budget`, `artifacts`, `modelCache`
And `mode` is `narrate`
And `budget` is `{"maxSentences":3,"maxSeconds":45,"wordsPerSecond":2.5}`
And `modelCache` is `.cache/voice/models`

## AC-044-01-03 — Print-config is inert
Given a fake opencode server started with a request recorder
And a temp artifacts directory that does not exist yet
When `voice-console.mjs --print-config --opencode-url <fake-url> --artifacts <temp> --tts-engine silent` runs
Then exit code is 0
And the recorder contains zero requests
And the temp artifacts directory still does not exist

## AC-044-01-04 — Flag beats environment beats default
Given `VOICE_MODE=converse` and `VOICE_OPENCODE_URL=http://127.0.0.1:4444` in the environment
When `voice-console.mjs --print-config --mode narrate --opencode-url http://127.0.0.1:5555` runs
Then `mode` is `narrate` and `opencodeUrl` is `http://127.0.0.1:5555`
And when the two flags are omitted, `mode` is `converse` and `opencodeUrl` is `http://127.0.0.1:4444`
And with the environment also cleared, `mode` is `narrate` and `opencodeUrl` is `http://127.0.0.1:4096`

## AC-044-01-05 — Unknown flag is a usage error
Given `--narrate-everything` is not a recognised flag
When `voice-console.mjs --print-config --narrate-everything` runs
Then exit code is 2
And stdout is empty
And stderr contains `--narrate-everything`

## AC-044-01-06 — Invalid mode is a usage error
Given a mode argument of `duplex`
When `voice-console.mjs --print-config --mode duplex` runs
Then exit code is 2
And stdout is empty
And stderr names `narrate`, `converse`, and `control`

## AC-044-01-07 — Sentence budget boundaries
Given `--max-sentences` accepts only integers of at least 1
When `--max-sentences 1` is passed with `--print-config`
Then exit code is 0 and `budget.maxSentences` is 1
And when `--max-sentences 0`, `--max-sentences -1`, `--max-sentences abc`, or `--max-sentences` with no value is passed
Then each exits 2 with empty stdout

## AC-044-01-08 — Narrate and control require a parent session
Given mode `narrate` with no `--session`
When `voice-console.mjs --print-config --mode narrate` runs
Then exit code is 2
And stderr names `--session`
And the same holds for `--mode control`

## AC-044-01-09 — Narrate rejects audio input
Given mode `narrate` and an audio-input flag
When `voice-console.mjs --print-config --mode narrate --session ses_x --audio-in file:/tmp/a.wav` runs
Then exit code is 2
And stderr states that narrate performs no capture

## AC-044-01-10 — Ledger schema
Given a run that wrote at least one ledger record
When `ledger.jsonl` is read inside the `--artifacts` directory
Then every line parses as a JSON object with keys `seq`, `kind`, `turn`, `text`, `rule`, `detail`
And `seq` values are 1..N with no gaps and no repeats
And no record contains a timestamp or a process id
And `kind` is one of `spoken`, `deferred`, `resumed`, `prompt-sent`, `reply-sent`, `refused`, `pending`, `ignored`, `skipped-utterance`, `cancelled`, `nothing-more`
