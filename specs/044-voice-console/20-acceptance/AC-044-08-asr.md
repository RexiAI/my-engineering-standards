# AC-044-08: Local speech recognition adapter

## AC-044-08-01 — Engine precedence
Given `scripts/voice/config.mjs` exports exactly one `ASR_DEFAULT_ENGINE` value drawn from `["faster-whisper","sherpa-onnx"]`
When no engine flag or variable is set
Then `--print-config` reports `asr.engine` equal to that constant
And with `VOICE_ASR_ENGINE=faster-whisper` it reports `faster-whisper`
And with `--asr-engine sherpa-onnx` on top of that variable it reports `sherpa-onnx`

## AC-044-08-02 — Unknown engine is a usage error
Given an engine value of `whisper-cpp`
When `voice-console.mjs --print-config --asr-engine whisper-cpp` runs
Then exit code is 2
And stderr names `faster-whisper` and `sherpa-onnx`

## AC-044-08-03 — File transcripts map by index
Given `--asr file:<tmp>/transcript.txt` containing two non-blank lines
And two captured utterances
When the adapter transcribes
Then utterance 1 gets line 1 and utterance 2 gets line 2 verbatim

## AC-044-08-04 — Missing transcript lines are skipped
Given a transcript file with one line and two utterances
When the adapter runs
Then the second utterance produces ledger `skipped-utterance`
And no prompt is sent for it

## AC-044-08-05 — Blank transcripts produce no prompt
Given a transcript line that is empty after trimming
When the adapter runs for that utterance
Then no `prompt-sent` record is written
And no request is sent

## AC-044-08-06 — No cloud path exists
Given `scripts/voice/asr.mjs`
When it is searched for `http://`, `https://`, and a `bl` spawn
Then none is present
And `--print-config` reports `modelCache` as `.cache/voice/models`

## AC-044-08-07 — Missing engine runtime is a dependency exit
Given a real engine selected and its package not importable
When the adapter is asked to transcribe
Then exit code is 3
And stderr contains `missing-runtime` and the engine name
And no audio file was read and no request was sent

## AC-044-08-08 — Documentation matches the single source of truth
Given `docs/VOICE_CONSOLE.md §Speech recognition`
When the shipped default engine is named
Then it equals `ASR_DEFAULT_ENGINE` from `scripts/voice/config.mjs`
And the other engine is named as a documented alternative
