# AC-026-07: secrets via env:, private key removed on exit

## AC-026-07 — No `${{ secrets.* }}` interpolated directly into a `run:` body; key file removed with `if: always()`

Given the `deploy` job in `ci-deploy-ssh.yml` needs `SSH_HOST`, `SSH_USER`,
`SSH_PORT`, `SSH_PRIVATE_KEY`, and other secrets/inputs inside its `run:`
steps
When those steps execute
Then every value is read from a shell variable populated by a job- or
  step-level `env:` block — no `run:` script body contains a literal
  `${{ secrets.` or `${{ inputs.` expression.

Given the job has finished (success, failure, or cancellation)
When the job's steps complete
Then a "Remove SSH private key" step with `if: always()` deletes
  `~/.ssh/id_rsa`.

Checkable by reading code:
- `.github/workflows/ci-deploy-ssh.yml`'s `deploy` job declares a job-level
  `env:` block mapping every secret/input the steps use.
- No `run:` block under the `deploy` job contains `${{ secrets.` or
  `${{ inputs.`.
- A step named "Remove SSH private key" exists with `if: always()` and
  `run: rm -f ~/.ssh/id_rsa`.
