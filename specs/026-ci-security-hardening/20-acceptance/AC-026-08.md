# AC-026-08: ci-sweeper invocation budget

## AC-026-08 — the sweeper skips cleanly past its daily invocation cap

Given `loop-budget.md §ci-sweeper` sets a cap of 20 sweeper invocations per
rolling 24h
When `ci-sweeper.yml`'s "Check sweeper invocation budget" step queries the
  Actions API for this workflow's own runs in the last 24h and finds the
  count above the cap
Then it sets `over-budget=true`, emits a `::warning::` citing the cap, and
  the "Install pinned opencode binary" and "Sweep the failing run" steps are
  both skipped (`if: steps.budget.outputs.over-budget != 'true'`) — no model
  invocation happens, and the job still exits 0 (not a failure).

Given the count is at or under the cap, or the API call itself fails
When the same step runs
Then `over-budget` is `false` and the sweep proceeds normally.

Checkable by reading code:
- `loop-budget.md` has a `## ci-sweeper` section stating the 24h cap.
- `.github/workflows/ci-sweeper.yml` has a "Check sweeper invocation budget"
  step producing an `over-budget` output, and the install/sweep steps below
  it are gated on `steps.budget.outputs.over-budget != 'true'`.
