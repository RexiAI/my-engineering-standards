# AC-026-10: Dependabot auto-merge restricted to patch bumps

## AC-026-10 — a semver-minor Dependabot PR is no longer auto-merged

Given Dependabot opens a PR with `update-type: version-update:semver-minor`
When `ci-dependabot.yml`'s "Approve & merge" step evaluates its `if:`
condition
Then it does not run — the PR requires a human's normal review and merge.

Given Dependabot opens a PR with `update-type: version-update:semver-patch`
When the same step runs
Then it approves and auto-merges the PR, unchanged from before.

Checkable by reading code:
- `.github/workflows/ci-dependabot.yml`'s "Approve & merge" step `if:` is
  `steps.metadata.outputs.update-type == 'version-update:semver-patch'` —
  it no longer contains `semver-minor` in that condition.
- The workflow documents the branch-protection prerequisite this
  automation depends on.
