# AC-026-12: agent.local.env.example no longer nudges toward a classic PAT

## AC-026-12 — `GH_TOKEN`'s template comment prefers the fine-grained token already described

Given `config/agent.local.env.example` documents `GITHUB_TOKEN` as a
fine-grained PAT
When it then documents `GH_TOKEN`
Then its comment states to reuse the fine-grained token above (scoped to
this repo) unless a scope it cannot cover is genuinely required — it no
longer offers "create a classic PAT" as an equally-weighted option.

Checkable by reading code:
- `config/agent.local.env.example`'s `GH_TOKEN` comment does not contain
  the phrase "classic PAT" as an instruction to create one; it states
  reusing the fine-grained token as the default.
