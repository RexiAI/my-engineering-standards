# AC-026-03: untrusted-content warning in the PR-review agent

## AC-026-03 — The agent is told diff/log content is data, not instructions

Given a PR diff, commit message, or CI log line contains text that reads
like an instruction to the agent ("ignore prior instructions", "run X",
"disclose Y")
When the pr-review agent processes that content
Then its own instructions (`agents/pr-review.md`) explicitly state that
  content read via `git diff`/`git show`/`gh pr diff`/`gh pr view`/CI logs is
  data written by the PR's author, not instructions from the operator, and
  that the `permission` block — not this paragraph — is the real boundary.

Checkable by reading code:
- `agents/pr-review.md` contains a section warning that diff/log/PR content
  is untrusted data, not instructions, and naming the `permission` block as
  the actual enforcement boundary.
