# AC-045-02: Changed-line accounting and exclusions

## AC-045-02-01 — Additions and deletions are summed
Given a numstat file with `12	8	src/a.ts` and `3	1	src/b.ts`
And a diff file with no exclusion markers
When `scripts/pr-size-gate.sh` runs
Then stdout contains `changed=24`
And `excluded=0`
And the exit code is 0

## AC-045-02-02 — Lockfiles are excluded
Given a numstat file with `500	500	package-lock.json` and `2	1	src/a.ts`
When the size gate runs
Then stdout contains `changed=3`
And `excluded=1`

## AC-045-02-03 — Generated code is excluded by path
Given a numstat file with `40	10	src/generated/client.ts` and `1	1	src/a.ts`
When the size gate runs
Then stdout contains `changed=2`
And `excluded=1`

## AC-045-02-04 — Generated code is excluded by content marker
Given a numstat file with `90	0	lib/api.go` and `2	2	src/a.ts`
And a diff file whose added lines for `lib/api.go` include
`// Code generated by protoc-gen-go. DO NOT EDIT.`
When the size gate runs
Then stdout contains `changed=4`
And `excluded=1`

## AC-045-02-05 — Snapshot files are excluded
Given a numstat file with `10	10	__snapshots__/a.test.ts.snap` and
`5	0	src/a.ts`
When the size gate runs
Then stdout contains `changed=5`
And `excluded=1`

## AC-045-02-06 — A pure file deletion is excluded
Given a numstat file with `0	700	old/legacy.ts` and `4	2	src/a.ts`
And a diff file that marks `old/legacy.ts` with `deleted file mode`
When the size gate runs
Then stdout contains `changed=6`
And `excluded=1`

## AC-045-02-07 — A file that only lost lines still counts
Given a numstat file with `0	50	src/still-here.ts` and `2	0	src/a.ts`
And a diff file that shows `src/still-here.ts` modified, not deleted
When the size gate runs
Then stdout contains `changed=52`
And `excluded=0`

## AC-045-02-08 — Binary entries contribute zero
Given a numstat file with `-	-	assets/logo.png` and `2	0	README.md`
When the size gate runs
Then stdout contains `changed=2`
And the exit code is 0

## AC-045-02-09 — A rename is counted once
Given a numstat file with `4	2	src/{old => new}/file.ts`
When the size gate runs
Then stdout contains `changed=6`
And `excluded=0`

## AC-045-02-10 — An empty diff counts zero
Given an empty numstat file and an empty diff file
When the size gate runs
Then stdout contains `changed=0`
And `excluded=0`
And the exit code is 0
