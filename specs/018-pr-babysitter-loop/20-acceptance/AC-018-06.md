# AC-018-06: state is kept, pruned each run, and loop comments are signed

## AC-018-06-01 — STATE.md keeps a PR Babysitter section
Given the 016 `STATE.md` file at the repo root
When the loop runs
Then `STATE.md` contains a `## PR Babysitter` section
And the section lists each watched PR with its number, branch, check summary, last action, and outcome
And it records human overrides that changed loop behavior

## AC-018-06-02 — Merged/closed PRs are pruned every run
Given a watched PR that is now merged
Or now closed
When a loop run observes it
Then the loop removes it from the `## PR Babysitter` section
And records the prune in the run-log

## AC-018-06-03 — Every loop comment is signed
Given a comment the loop writes on a PR
When the comment is posted
Then it contains the exact string `Loop Engineering — PR Babysitter`

## AC-018-06-04 — Each run appends a run-log entry
Given a completed loop run, including a no-op run
When the run finishes
Then the loop appends one JSON entry to `loop-run-log.md` in the 016 format
And the entry carries run_id, pattern "pr-babysitter", duration_s, items_found, actions_taken, escalations, tokens_estimate, and outcome
