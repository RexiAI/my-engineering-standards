# AC-018-07: cost guidance documented with early exit on an empty watchlist

## AC-018-07-01 — Empty watchlist exits early
Given a loop run where `gh pr list --state open` returns zero PRs
When the watcher completes
Then the loop exits immediately after appending the no-op run-log entry
And it performs no triage, spawns no sub-agents, and posts no comments

## AC-018-07-02 — Cost table and budget consumption are documented
Given the triage skill
When the cost guidance is read
Then it documents the cost table for no-op, triage, and fix-attempt runs
And it states budget is spent from the 016 `loop-budget.md` with the on-exceed and kill behavior defined there
