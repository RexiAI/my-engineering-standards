# AC-018-08: a shell check script carries every AC-018-ID and is wired into CI

## AC-018-08-01 — The check script exists and gates on completeness
Given the repo root
When `scripts/check-pr-babysitter.sh` is run
Then the script exists and is executable
And it exits 0 only when every check passes
And it exits 1 and prints a FAIL line per violation otherwise

## AC-018-08-02 — Every scenario ID is cited by the script
Given the scenario IDs in `20-acceptance/AC-018-*.md`
When the check script is run
Then every AC-018-NN-NN ID appears in `scripts/check-pr-babysitter.sh`
And every AC-018 reference inside the script resolves to a real scenario heading
So that `scripts/check-scenario-traceability.sh` traces this spec

## AC-018-08-03 — The script is wired into self-ci
Given the existing `Validate` job in `.github/workflows/self-ci.yml`
When CI runs on a PR touching this spec
Then the job runs `./scripts/check-pr-babysitter.sh` as a step
And no new workflow file is added
